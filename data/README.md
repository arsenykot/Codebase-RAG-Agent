# Папка для репозитория

Скопируйте или клонируйте Python-проект сюда:

```
data/repo/          ← содержимое репозитория (рекомендуется)
```

или положите папку прямо в `data/`:

```
data/my-project/
```

Затем из корня проекта:

```bash
python main.py index
python main.py ask
```

Если в `data/` лежит несколько папок — оставьте одну или укажите путь явно:
`python main.py index data/my-project`
